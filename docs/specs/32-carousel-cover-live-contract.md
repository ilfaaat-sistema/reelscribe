## Бюджет v2

Серверный режим по умолчанию pilot:20attempts всего. После реальной приёмки корень переводит режим в live через закрытую SQL RPC. Live:500attempts за календарные сутки Europe/Moscow, включая pilot-вызовы того же дня. Lifetime счётчик и результаты не обнулять; смена версии и режима не возвращает попытки. Учитывается фактическая зарезервированная попытка, не только успешный перевод.

Все резервации и переключение режима сериализуются на общей строке бюджета. Два глобальных слота сохраняются. Можно считать сутки по created_at зарезервированных строк с claim_token; image_unavailable без модели не учитывается. В тестах проверить границу московской полуночи и переход pilot→live без сброса счётчиков. Переключение режима доступно только service_role; anon/authenticated не имеют прямых прав на таблицы/RPC. Метаданные не могут повышать лимиты.

Миграция 20261020123535 уже применена штатным db push после сверки полного remote manifest и всех pending. Повторное применение или редактирование применённой миграции не требуется. Будущие изменения — отдельной миграцией через CLI, после проверки всех ожидающих файлов. Никаких repair-reverted/apply_migration/обходного прямого DDL. Наличие Production-ключа проверено по метаданным; повторный ввод не требуется.

## API дополнения (обратно совместимые)

База прежняя /api/radar/carousel-cover-translations. POST body прежнее {period}.
Item добавляет retry_after: ISO UTC timestamp|null. Для исчерпанного суточного бюджета status=limit_reached, retry_after — ближайшая полночь по Москве; для пилотного ограничения retry_after=null. Никогда не объявлять ограничение ошибкой распознавания.
GET добавляет budget: {mode:'pilot'|'live', pilot_limit:20, daily_limit:500, reset_at:ISO UTC}. На чтении missing ID с исчерпанным бюджетом возвращается limit_reached с retry_after; готовые и терминальные строки возвращаются как есть. Чтение не запускает модель. При limit_reached сretry_after клиент ждёт до этой даты, затем сначалаGET и только при missing/visible/enabled запускаетPOST. Не держать setTimeout дольше безопасного int32; при focus/visibilitychange сверять время заново. Pilot-limit не опрашивать бесконечно.

Сервис translate(media_id, period, *, oidc_token=None). Внутри create_vertex_client(oidc_token=oidc_token). Корень добавляет получение токена из Request header в API и адаптер авторизации. Токен не писать в ответ/БД/логи. Ошибка auth до модели возвращает безопасную503, не fallback.
