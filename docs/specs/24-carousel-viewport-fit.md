# Карусель целиком в высоте экрана

19.10.2026 пользователь уточнил после первой правки: при масштабе Chrome 100% первый слайд `@serditov` всё ещё уходит ниже экрана, а четыре метрики занимают два ряда и отнимают высоту у текста.

На широком экране панель просмотра использует доступную ширину до 1180 px. Instagram-вставка получает ширину из высоты окна с расчётом на портретный слайд 4:5 и элементы Instagram; её высота укладывается в окно. При маленькой высоте левая часть может прокручиваться самостоятельно. Правая часть прокручивает длинное описание отдельно, четыре метрики стоят в одной строке. Мобильная верстка ниже 701 px сохраняет прежнюю вертикальную прокрутку.

Приёмка: тот же пост `serditov` на экране 100%, полная нижняя часть первого слайда и доступность стрелки карусели, одна строка метрик, больше места под текст; отдельно проверить прокрутку описания и мобильную ширину. Правка ограничена CSS окна просмотра и не меняет данные или сбор.
