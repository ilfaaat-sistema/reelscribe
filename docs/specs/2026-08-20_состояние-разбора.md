## Что оказалось сломано (и почему пауза 10.08 объясняла это неверно)

Расписание воркера остановили 10.08 с формулировкой «все платные источники исчерпаны». Разбор
19.08 показал другое: квота уходила **на промахи**, а не на работу.

1. **Первый источник каскада искал не там.** `sones/instagram-posts-scraper-lowcost` (профильный)
   ищет рилс в свежих постах автора — глубина задаётся `apify_profile_limit`, стояло 120.
   Сохранённые рилсы старые, в эти 120 постов не попадают. Замер на прогоне: **0 попаданий из 31**,
   при цене $0.041 за вызов (тариф по событиям: $0.005 старт + $0.0003 за пост выдачи).
   За два прогона сгорело **$2.01** без единой расшифровки.

2. **Дешёвый источник лежал выключенным.** `apify/instagram-scraper` берёт рилс по прямой ссылке
   за **$0.0027** — в 15 раз дешевле — и не зависит от глубины ленты. В каскаде он стоял
   последним под флагом `apify_single_fallback = False`, судя по всему, с тех времён, когда Apify
   считал по compute units.

3. **Просмотры терялись молча.** Одиночный актор отдаёт их в `videoPlayCount`, а код читал
   `videoViewCount`, который у этого актора всегда `null`. На просмотрах держится залётность `er`.

4. **ffmpeg падал не по своей вине.** Instagram отдаёт медиа DASH-представлениями, и `videoUrl`
   часто указывает на дорожку **без звука** (проверено на `DRnVrkNAMtn`: vp9 1080x1920, 17.7 c,
   ни одного аудиопотока). Рядом в ответе лежит `audioUrl` с чистым звуком — его код не
   использовал. Это держало 21 задание в вечных ретраях.

## Что сделано

* `apify_single_primary` (`backend/app/core/config.py`) — одиночный актор первым источником;
  профильный при этом флаге пропускается целиком, чтобы промах не стоил как 15 рилсов.
* `backend/app/pipeline/download.py` — нулевой шаг каскада под этим флагом.
* `backend/app/pipeline/apify_downloader.py` — хелпер `_media_url`: сначала `audioUrl`, потом
  `videoUrl`. Побочно это в 24 раза меньше трафика (179 КБ против 4.4 МБ на том же рилсе) и
  точнее по правилу «видео не хранить» — видео теперь вообще не скачивается.
* `.github/workflows/worker.yml` — `APIFY_SINGLE_PRIMARY: '1'`, один шард.

**Цена после починки: $0.0075 за рилс** (одиночный актор + добор подписчиков через
`apify/instagram-profile-scraper` по $0.0026 за автора, с учётом попаданий в `followers_cache`).
174 расшифровки обошлись в $1.30.

## Что осталось сделать

### 1. Импортировать 255 ссылок — главный кусок

Не заведены в базу вообще: хвосты `партия_04_110шт.txt` и `остаток_после_14_августа_190шт.txt`
в папке `your_instagram_activity 2/партии/`. Дубли по `shortcode` база отсекает сама, поэтому
из 300 строк новых ровно 255.

Полная стоимость ~$1.9. **В текущем цикле денег нет** — см. ниже. Варианты: импортировать
частями по остатку, дождаться нового цикла 15 сентября, либо завести второй аккаунт Apify.

### 2. Двадцать один рилс без задания в очереди

В базе есть рилсы со статусом `queued`, у которых нет записи в `jobs` — воркер их не видит,
потому что забирает работу именно из `jobs`. Нужно создать им задания. Стоимость ~$0.15.
Отложено сознательно (решение владельца 19.08), не забыто.

### 3. Ротация ключей RapidAPI

Ключи лежат открытым текстом в файле памяти сессий и засветились в переписке 19.08.
Перевыпустить в кабинете RapidAPI, хранить только в `backend/.env` (`RAPIDAPI_KEYS`).

  сброс 1 числа. Тариф Pro $9.90 даёт 10 000 запросов — при цене ~2 запроса на рилс это закрыло

  reached or login required».

## Как продолжить

Расписание в `.github/workflows/worker.yml` намеренно закомментировано — прогоны запускаются
руками, чтобы расход был виден:

```bash
gh workflow run worker.yml            # запустить разбор очереди
gh run list --workflow=worker.yml     # посмотреть, что идёт
```

Перед запуском вернуть в очередь незавершённое:

```bash
cd backend && python -m app.workers.requeue --all
```

Подписчиков к уже расшифрованным рилсам добирает `backend/app/workers/backfill_followers.py`
отдельным проходом — одиночный актор их не отдаёт (`ownerFollowersCount` всегда `null`).

**Watchdog по деньгам.** Квоту смотреть до и после прогона, иначе повторится история 19.08,
когда $2 ушли молча:

```bash
curl -s -H "Authorization: Bearer $APIFY_API_TOKEN" \
  https://api.apify.com/v2/users/me/limits | jq '.data.current.monthlyUsageUsd'
```

Если цена за рилс уползла выше ~$0.01 — смотреть, какой актор её тянет, через
`https://api.apify.com/v2/actor-runs?desc=1&limit=40` (поле `usageTotalUsd`). Именно так и
нашлась причина.
