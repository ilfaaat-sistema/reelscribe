# ReelScribe — реестр ТЗ

Каждое улучшение описывается отдельным документом по шаблону [`_template.md`](_template.md) и
проходит статусы: **идея → ТЗ → в работе → готово**. Порядок работы (постоянный worktree на модуль,
кто какой моделью пишет, как финализируется итерация) — в скилле `module-flow` и корневом
`CLAUDE.md`.

Документы, заведённые до реестра, названы по дате, а не по номеру — переименовывать их не стали,
на них ссылаются коммиты и память сессий.
