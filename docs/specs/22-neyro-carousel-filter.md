# Фильтр каруселей по источнику NEYRO_SET7

Прямая ссылка: `/radar/carousels?source=neyro_set7`. Она показывает карусели авторов, которые уже имеют метку `neyro_set7` в существующей истории рилсов. Метка считывается только на сервере из уже публичного фильтра `reel_sources.account`; новый список авторов не публикуется и новый сбор Instagram не запускается.

POST `/api/radar/carousels` принимает только `source_account: "neyro_set7"` или отсутствие поля. Имена из истории выбираются лёгким запросом `author_handle` с `reel_sources!inner(account)`, постранично и с пятиминутным кэшем. Сервер пересекает их с избранными и исключает скрытых до сортировки и пагинации; `total` соответствует карточкам сетки. Обычный GET и остальные фильтры работают прежним образом. В интерфейсе есть переключатель «Только NEYRO_SET7» и заголовок источника.

Сверка сохранённой истории: 580 из 583 авторов уже представлены в публичных метках БД. Трое без метки на момент сверки не имеют найденных каруселей в недельном отчёте; поэтому текущий результат их не теряет. Если у них появятся карточки или метки истории будут дополнены, покрытие следует пересверить. Не считать этот фильтр доказательством наличия каруселей у каждого автора.
