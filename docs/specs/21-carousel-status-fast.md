# Быстрый ответ о ходе сбора NEYRO_SET7

Когда пользователь спрашивает «сколько сейчас», из корня репозитория выполнить `python3 scripts/carousel_status.py`. Скрипт делает один запрос к опубликованному файлу отчёта в ветке данных GitHub, локально пересекает готовые `profiles` с каталогом истории и выводит только агрегаты. Личный список имён никуда не передаётся и не печатается.

Источник локального каталога: `../Материалы планирования/2026-10-18-авторы/authors.json`. Он нужен только на рабочем Mac. На другой машине передать файл штатным путём или указать `--authors-file`; без каталога нельзя точно посчитать группу. Дата `обновлено` относится к опубликованному отчёту. Запрос к файлу добавляет поминутный параметр, чтобы не полагаться на старый кэш API сайта. Уточнять checkpoint GitHub нужно только при спорном статусе или несоответствии.

В публичном отчёте авторы со статусом `unavailable` имеют `carousels: null`, как и ещё не обработанные. Поэтому по одним `profiles` число завершённых занижено. При включении приоритетного порядка из checkpoint подтверждены 219 уже завершённых авторов вне NEYRO_SET7. Пока очередь сперва проходит эту группу, точное число её завершённых равно `collection.checked - 219` (с ограничением 0–583); число каруселей складывается из доступных профилей. При изменении порядка очереди или выборки этот базовый счётчик нужно пересверить с checkpoint и обновить. Скрипт сигнализирует о невозможных значениях вместо тихого ответа.
