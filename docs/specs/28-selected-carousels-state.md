# Отбор каруселей — состояние реализации 20.10.2026

Рабочая ветка `feature/selected-carousels`, постоянный worktree `worktrees/selected-carousels`, база `53d6026`. Основное ТЗ: `28-selected-carousels.md`. Чужие изменения в `main` не затронуты. Изменения этого worktree пока не смержены и не опубликованы.

## Сделано локально

- Отдельная кнопка публикации в общей сетке и drawer; звезда и скрытие автора сохранены.
- Вход по email OTP, личный список, поиск/сортировки/счётчик/снимок публикации, снятие и отмена, синхронизация фокусом и интервалом.
- Приватные API с проверкой JWT; миграция для личной таблицы с RLS, прямой записью только через защищённые RPC. Снимок сохраняется независимо от обновлений отчёта. Проверка наличия в отчёте — одним запросом на страницу, отсутствие и 503 различаются.
- Исправлены найденные при критическом обзоре гонки смены аккаунта/опроса и обновления токена во время записи, повторный вход после 401, returnTo, конфликт версии и жизненный цикл отложенного намерения. Повторный read-only обзор подтвердил исправления, оставшийся риск застрявшей кнопки после token refresh устранён сбросом `busy` при смене токена.
