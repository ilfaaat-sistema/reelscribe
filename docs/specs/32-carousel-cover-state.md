# Статус перевода обложек каруселей

Реализован перевод основного смыслового текста первого изображения карусели, включая читаемые диалоги на скриншотах. На карточке выделены четыре строки, полный перевод и исходный текст доступны в панели публикации. Перевод подписи публикации в этот модуль не входит.

Кэш хранится по ID публикации и версии обработки. Запуск требует 500 мс непрерывной видимости карточки и видимой вкладки. Клиент предварительно читает кэш; одновременно допускаются два запроса клиента и две глобальные обработки.

Бюджет поддерживает два режима: pilot — 20 попыток всего; live — 500 попыток за календарные сутки Europe/Moscow. Исчерпание live-бюджета возвращает retry_after; после этой даты клиент сначала читает кэш. Неопределённые исходы и оплаченные ошибки автоматически не повторяются.

Используется Vertex AI с отдельным адаптером авторизации. Публикация, проверка окружения и переключение режима выполняются отдельным этапом выпуска. Данные и результаты сохраняются при выключении новых обработок.

Технические условия описаны в 32-carousel-cover-live-contract.md, эксплуатационные действия — в 32-carousel-cover-operations.md, результаты проверок — в 32-carousel-cover-review.md.

Конфигурация выпуска 23.10.2026: `gemini-3.1-flash-lite`, `thinkingLevel=LOW`, системная инструкция `cover-readable-v4`, явная нормализация `jpeg2048`. Общий кэш `cover-v1` сохраняет принятые результаты прежних моделей и ревизий. Все 20 сохранённых результатов приняты; проверка завершена на 29 попытках из разрешённых 30. Повторов принятых результатов не было.
