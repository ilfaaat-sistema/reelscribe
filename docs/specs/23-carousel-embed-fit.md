# Полный просмотр Instagram-карусели

19.10.2026 пользователь показал обрезанную Instagram-вставку: при ширине карточки около 470 CSS px у iframe стоял предел высоты 710 px (либо высота экрана минус 160 px). Квадратный слайд, шапка и нижняя часть Instagram вместе выше этого предела; отдельная ссылка «Открыть в Instagram» не заменяет просмотр в панели.

Исправление ограничено CSS окна карусели. Высота iframe теперь зависит от его ширины: сторона квадратного медиа плюс место под шапку, действия и подпись Instagram; минимум 800 px. Панель прокручивается целиком, поэтому при невысоком экране карусель и внешняя ссылка остаются доступны. При узкой ширине iframe по-прежнему не шире 440 px. Сетка, скрытые/избранные, фильтр NEYRO_SET7 и сбор данных не меняются.

Приёмка: сравнить исходный скриншот с экраном после правки, проверить обрезку первого и следующих слайдов, доступность нижних элементов и ссылки, прокрутку панели и мобильную ширину. Выполнить production build и визуальный проход опубликованного экрана. Instagram может менять внутреннюю разметку; если подпись длиннее выделенной области, её можно дочитать внутри вставки или открыть оригинал.
