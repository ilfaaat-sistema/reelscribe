# Избранные авторы каруселей

19.10.2026 пользователь выбрал четыре публичных Instagram-профиля для быстрого просмотра их каруселей. В сетке `/radar/carousels` появился переключатель «Только избранные», список авторов и звезда на карточке для изменения списка.

Список начинает с четырёх указанных пользователем профилей и хранится в localStorage основного домена. Отдельные локальные адреса имеют отдельное хранилище. Пустой сохранённый список остаётся пустым. Список синхронизируется между вкладками; ошибки хранилища видны пользователю.

Фильтр `favorite=1` сохраняется в URL. Клиент отправляет `include_authors` в POST `/api/radar/carousels`; сервер ограничивает выборку до сортировки и пагинации, затем применяет прежнее исключение скрытых авторов. `include_authors: []` даёт пустую выборку. Без этого параметра прежнее поведение API не меняется. Данные отчёта и очередь Meta не затрагиваются.

Приёмка: четыре автора по умолчанию, счётчик и карточки только выбранных, пустой список, звезда и повторное открытие страницы, совместимость со скрытием и авторским фильтром, сборка, затронутые backend/frontend тесты, итоговый скриншот основного сайта.
